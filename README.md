# 基于机器学习 SYK 造血信号激酶调控分子选择性判别模型

> 针对 SYK 在 B 细胞与免疫信号中的核心地位，构建调控分子活性判别模型，支撑自身免疫与 B 细胞淋巴瘤靶点研究。

## 一、方法

- **模型**：GATv2 图注意力网络 + 注意力聚合读出

- **输入**：分子图（原子节点 + 化学键边，RDKit 解析 SMILES 得到）
- **训练规模**：2500 条样本，2 类
- **标签协议**：rel
- **验证**：5 折分层交叉验证 × 3 随机种子 = 15 次独立训练
